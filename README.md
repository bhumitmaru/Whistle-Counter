# Whistle Counter

A browser-based application that automatically detects and counts pressure cooker whistles using your device's microphone.

Set your target number of whistles, start listening, and let the application keep track of the count.

> **Note:** Whistle Counter is a cooking aid, not a timer or safety device. Sound detection may occasionally miss or miscount whistles depending on background noise, room acoustics, distance, and microphone quality.

## Features

- Automatic whistle detection using the device microphone
- Real-time whistle counting
- Custom whistle target
- Alert when the target count is reached
- Local browser-based audio processing
- No audio uploads
- No account required
- Responsive interface
- Built-in usage guide and FAQ

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Web Audio API
